Sistema de diseño

Catálogo vivo. La fuente de verdad es design/tokens.json; este CSS se genera con python -m scripts.gen_tokens. Identidad completa en design/BRAND.md.

Isotipo — “el waypoint”

Un arco de trayectoria y la carga (punto ámbar) saliendo por él. Monocromo + un solo color. A 16px el trazo y el punto crecen para conservar la lectura.

Color — “bitácora de rampa”

Todos los pares texto/fondo se validan a ≥ 4.5:1 en ambos temas (ratios documentados en tokens.json). El azul de foco es exclusivo del anillo de foco.

Tipografía

Display 1.45rem / 650 — títulos de vista

Sección 1.1rem / 650

Cuerpo 1rem / 400 — nunca menor a 16px, líneas ≤ 65 caracteres

Pista 0.9rem — explicaciones bajo cada campo

Dato 0.8rem / 650 — pills y etiquetas

Monoespaciada para datos: $93,600 · 97.5° · 550 km (números tabulares alinean solos)

Botones

Altura mínima 48px (token size.control). El foco siempre dibuja el anillo azul: pruébalo con Tab.

Pills de estado

Borrador Con precio Reservado Cancelado

El estado siempre en palabras humanas. Verde = hecho consumado; ámbar = requiere tu acción; rojo = bloqueo.

Tarjeta de opción

Respuesta tri-estado

“No estoy segura/o” es una respuesta de primera clase: nunca bloquea, deriva a revisión humana.

Campo con error

Ese peso supera los 500 kg de este servicio. Si tu carga pesa más, escríbenos y te conectamos con un lanzamiento dedicado.

El error siempre dice qué pasó y qué hacer — nunca solo “valor inválido”.
